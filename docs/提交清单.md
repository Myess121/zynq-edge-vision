## 需要你本人用手机拍的照片（只有这两类）

1. **作品全貌图**：开发板 + OV5640 摄像头 + 显示器摆在一张干净的桌面上。先开机等约 2 分钟，等显示器上出现检测画面，在镜头前放一个能识别的物体（手机、杯子、瓶子或你本人），让屏幕上有绿框。站在斜上方约 45° 把三样东西拍进同一张，开灯，避免屏幕反光。
2. **开发板重要角度高清照片**：
   - 正面俯拍：整块板子，能看清 ZYNQ 芯片和丝印；
   - 摄像头特写：OV5640 模组和排线接口；
   - 接口侧面：HDMI、PS 网口、USB_UART、电源口；
   - 启动拨码 BOOT_CFG 特写（两位都在 OFF，即 SD 卡启动）和 TF 卡槽。

拍摄要点：手机用原相机最高画质，对焦清晰，背景干净；拍板子时可以关掉显示器，减少反光。
